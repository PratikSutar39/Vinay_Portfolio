# Vinay Manke Portfolio

A responsive, dependency-free Python portfolio website with a cinematic hero, resume content, image assets, and YouTube project sections that open in an on-page player.

## Run locally

```powershell
python app.py --open
```

Then visit `http://127.0.0.1:8000`.

If port 8000 is busy:

```powershell
python app.py --port 8080 --open
```

The site uses only Python's standard library. No package installation is required.
